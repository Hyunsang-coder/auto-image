Mac용 무료 다운로드

개인정보처리방침

Screenshot Studio는 내 Mac 안에서만 동작하는 도구입니다. 계정도, 데이터베이스도, 데이터를 보낼 저희 서버도 없습니다. 이 페이지는 그럼에도 일어나는 몇 가지를 적어 둡니다. 최종 수정: 2026년 9월 14일.

스크린샷과 프로젝트는 내 Mac을 떠나지 않습니다

  • 프로젝트는 스크린샷까지 담긴 .studio.zip 파일입니다. 다른 곳에 저장하지 않으면 ~/Documents/Screenshot Studio/에 있습니다. 아직 저장하지 않은 작업은 앱이 비정상 종료돼도 되살릴 수 있도록 앱 자체 폴더에 사본이 남습니다. 모두 내 Mac 안의 파일이며, 어디에도 업로드되지 않습니다.
  • 내보내기(PNG 렌더링)는 전부 내 컴퓨터에서 이뤄집니다.
  • 프로젝트 파일과 앱 데이터를 지우면 전부 사라집니다. 저희는 사본을 가진 적이 없으니 남는 것도 없습니다.

수집하는 것: 웹사이트 집계 통계

이 웹사이트는 개인정보를 우선하는 쿠키 없는 분석 서비스 Cloudflare Web Analytics를 씁니다. 페이지 조회수와 성능 지표를 집계할 뿐, 쿠키나 localStorage를 쓰지 않고, 방문자를 식별하거나 사이트를 넘나들며 추적하지 않습니다. 저희가 보는 것은 사람이 아니라 숫자입니다.

호스팅

이 사이트는 GitHub Pages에서 제공되고, 앱은 GitHub Releases에서 내려받습니다. 여느 웹 호스트처럼 GitHub는 서비스 운영을 위해 IP 주소 같은 일반적인 요청 정보를 기록할 수 있습니다 — GitHub 개인정보 보호정책을 참고하세요.

앱이 보내는 요청 하나

앱은 실행할 때 GitHub 릴리스 API에 새 버전이 있는지 물어보고, 있으면 「새 버전」 표시를 띄웁니다. 이 요청에는 사용자나 프로젝트에 관한 정보가 전혀 담기지 않습니다 — 식별자도, 프로젝트 데이터도, 사용 중인 버전조차 없습니다. GitHub가 보는 것은 여느 다운로드와 마찬가지로 IP 주소와 ScreenshotStudio라는 사용자 에이전트뿐입니다. 저희에게 전달되는 것은 없습니다. 받을 서버가 없으니까요.

앱에서 끌 수 있습니다: 더 보기 ··· → 시작할 때 확인. 같은 메뉴의 업데이트 확인은 누를 때만 동작합니다.

연결한 AI 에이전트가 열린 프로젝트를 편집하게 해 주는 MCP 브리지는 로컬 유닉스 소켓입니다. Mac 밖으로는 아무것도 나가지 않으며, 앱 헤더에 별도의 스위치가 있습니다.

수집하지 않는 것

  • 계정, 로그인, 개인 프로필이 없습니다.
  • 광고 식별자와 광고 쿠키가 없습니다.
  • 앱 안에서는 어떤 분석도 하지 않습니다 — 위의 업데이트 확인이 앱이 보내는 유일한 요청입니다.
